# Bundled ad and tracking filters

EasyList and EasyPrivacy are maintained by **The EasyList authors**,
https://easylist.to/. These unmodified snapshots were downloaded on
2026-11-12 from:

- https://easylist.to/easylist/easylist.txt
- https://easylist.to/easylist/easyprivacy.txt

The upstream version, commit and modification time appear in each file.
Their licensing declaration is https://easylist.to/pages/licence.html:
the EasyList repository is dual licensed under GPL-3.0-or-later or
CC-BY-SA-3.0-or-later. This distribution uses GPL-3.0-or-later; its complete
text is included in LICENSE-GPL-3.0.txt. The filter source is the included
text itself. These assets are separate from WorldTube's AGPL license.

The app updates these same two lists over HTTPS after four days, retaining
installed filters if a download or validation fails. Manual updates are in
Account & privacy. Cached lists contain no account credentials. Network
filtering uses @ghostery/adblocker, licensed MPL-2.0, with its notices in the
packaged dependency license inventory. Cosmetic/page-injection filters are
not used: the application renders its own interface and plays direct media.
